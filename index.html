ML Model Architecture & Pipeline

Technical workflow overview of the XGBoost Regressor model trained on UCI Adult Income dataset concepts.

01

Data Collection

Dataset compiled from UCI Adult Income & Bureau of Labor Statistics benchmarks (48,842 rows) cleaned for outliers and missing values.

02

Preprocessing

Categorical features mapped via One-Hot & Label Encoding. Numerical features normalized using MinMaxScaler (0 - 1 range).

03

XGBoost Training

Trained using 500 gradient boosted decision trees, max_depth=6, learning_rate=0.05, optimizing MSE with 5-fold cross-validation.

04

Model Export

Serialized with joblib for instant production inference and embedded WebAssembly / JS real-time client simulator.
